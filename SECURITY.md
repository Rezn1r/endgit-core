# Security Policy

## Supported Versions

Only the latest `main` branch and official releases are supported with security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them to **security@endgit.dev**. We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If you report a vulnerability, you will be credited once it is resolved.
